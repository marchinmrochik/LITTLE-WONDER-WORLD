# Memory Match - desktop 0.8.0

Six of ten educational games now have complete desktop increments, plus Foxie's meadow. Physical Android acceptance remains pending.

## Delivered behavior

Find the pairs / Знайди пари uses twelve familiar original pictures: Cat, Dog, Rabbit, Bear; Apple, Banana, Carrot, Strawberry; Circle, Square, Star, Heart. Easy/Normal/Advanced select2/3/4 distinct pairs and shuffle exactly two cards per picture. No countdown, mistake limit or punishment.

The child opens a card, hears its English name and can repeat that word. One flip must finish before the next reveal. The second reveal locks further selections through pair holding and any hide animation. Matching cards stay open; different pictures remain visible briefly then smoothly close. English word playback finishes during the short hold before localized reaction speech. Correct pairs count as completed tasks. Only actual second reveals count as attempts; repeated/third/matched-card input cannot duplicate them. All pairs are required for session celebration and replay.

Reduced motion switches faces immediately. Parent overlays/focus loss pause active flip/hold/hide work. Restart invalidates old callbacks through a generation token and rebuilds a closed deck. Leaving during flips/holds/hides stops work and speech; stored progress is real practice counters, not hidden-card positions.
