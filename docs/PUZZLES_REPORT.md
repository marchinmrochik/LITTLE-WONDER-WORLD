# Animal Puzzles - desktop 0.7.0

Delivered 2026-11-13. Five of ten educational games now have complete desktop increments; Foxie meadow is additional. Android acceptance remains pending.

## Delivered behavior

Animal puzzles / Пазли з тваринами reuses six original illustrations: Cat, Dog, Rabbit, Bear, Lion and Elephant. A session chooses three distinct pictures. Easy has two parts (2x1), Normal four (2x2), Advanced six (3x2). Each tray piece is an AtlasTexture crop from the corresponding original image, not a repeated/scaled whole animal. Tray order is shuffled.

The child drags parts onto a 360x360 image surface. The matching region is highlighted; a correct part snaps and stays, a wrong part returns. Near-edge tolerance is ten logical pixels with nearest unfilled cell resolution. Outside/occupied/canceled drops do not count attempts. Single-pointer ownership prevents another finger or repeated release from placing the piece. Focus loss, parent overlay, Escape and exit cancel safely; snap and celebration animations pause appropriately.

Easy starts with a translucent template; Picture hint toggles it at any difficulty. Restart picture resets only the current picture. The first two finished pictures remain visible until Next picture is pressed; that button cannot skip an incomplete puzzle. Completing all parts of the third image ends the session with celebration/replay. Reduced motion settles pieces without movement. The English animal word is repeatable under either UI locale; helper reactions follow EN/UK. Real attempts/placements/sessions save under puzzles; repeated practice after a restart is still actual practice, not a mastery assessment.

## Implementation and assets

PuzzleRound owns image selection, crop geometry, piece/slot identity and completion. animal_puzzles.gd owns board/tray rendering, hint and snap feedback. Shared PointerDrag, DragCard, catalogs, local audio and persistence are reused. No copied image files or new external artwork are needed. The activity menu now has a reviewed 3-column/two-row grid with six large cards, wrapped titles and real available activities only.

Ten new helper WAVs were generated by PUZZLES_ prefix, preserving previous132 clips and reusing the six English animal words. Current pack:142 files,7,339,844 bytes,duration0.66-2.74s. Cori/Lada models and gentler processing unchanged; subjective voice/pronunciation approval remains pending. No new download, runtime dependency or user installation required for desktop play.
